==================================================
Test Plan: AWS EC2 Instance Containment Script
==================================================
Version: 1.1
Date: 2025-04-18

--- Introduction ---
This plan outlines testing for the AWS EC2 Instance Containment Script. It verifies the script's workflow for isolating instances, preserving evidence, and neutralizing threats in a controlled AWS test environment. Testing involves modifying AWS resources and requires appropriate permissions.

--- Test Objectives ---
- Verify successful execution of all script stages.
- Validate user prompts, confirmations, and optional step handling.
- Confirm correct creation/modification of AWS resources (Security Groups, IAM Policies, Snapshots, etc.).
- Ensure accurate logging and error handling.
- Validate cleanup instructions.

--- Test Environment ---
- Dedicated AWS Test Account/VPC.
- Test EC2 Instance (Linux/Windows) with IAM Role, EBS Volume(s). (Optional: IMDSv1 enabled, SSM Agent running).
- Temporary AWS credentials with permissions from README.
- Machine with Python 3, Boto3, Colorama.

--- Test Execution Stages & Steps ---
